# SuXXES – Sustainability Extension for XES Event Logs

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.17756035.svg)](https://doi.org/10.5281/zenodo.17756035)

SuXXES is a XES extension that enables a uniform integration of
sustainability-related data into case-centric event logs. It considers all three
dimensions of sustainability: economic, environmental, and social.

> This extension is associated with a scientific publication (accepted,
> forthcoming 2026, Springer Nature Switzerland AG). The `.xesext`
> definition file is released independently under CC BY 4.0.

---

## Dimensions

SuXXES covers the following 10 sustainability dimensions at the event level:

### 💼 Economic
| Dimension | Key | Description |
|---|---|---|
| Sustainability Management | `smanagement` | Sustainability certificates and initiatives associated with the business process |

### 🌍 Environmental
| Dimension | Key | Description |
|---|---|---|
| Energy | `energy` | Energy used in the business process |
| Emission | `emission` | Emissions generated by the business process |
| Water | `water` | Water usage of the business process |
| Waste | `waste` | Waste produced in the business process |
| Material | `material` | Materials used in the business process |

### 👥 Social
| Dimension | Key | Description |
|---|---|---|
| Employee | `employee` | Employee-related information of the business process |
| Workplace | `workplace` | Workplace-related information of the business process |
| Safety | `safety` | Accidents and safety incidents in the business process |
| Stakeholder | `stakeholder` | Stakeholder satisfaction related to the business process|

## Extension File

The SuXXES extension definition file (`.xesext`) is available here:

📄 **[SuXXES.xesext](https://nathalietum.github.io/SuXXES/suxxes.xesext)**

To reference this extension in your XES event log, add the following
extension declaration:
```xml
<extension name="SuXXES"
           prefix="suxxes"
           uri="https://nathalietum.github.io/SuXXES/suxxes.xesext"/>
```

## Example Event Logs

Example event logs applying the SuXXES extension are publicly available
on Zenodo:

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.17756035.svg)](https://doi.org/10.5281/zenodo.17756035)

**Wolf, N., Wittges, H., Rinderle-Ma, S. (2025).**
*SuXXES Event Logs: Synthetic and ERP-Based Process Data with Integrated
Sustainability Data.* Zenodo.
https://doi.org/10.5281/zenodo.17756035

The dataset contains four event logs covering diverse scenarios:

| Log | Type | Process |
|---|---|---|
| `SuXXES_Synthetic_ProductionProcess_SustainabilityLog.xes` | Synthetic | Wooden chair production (SimPy, PM4Py) |
| `SuXXES_ERPbased_P2PProcess_SustainabilityLog.xes` | ERP-based (SAP S/4HANA) | Procure-to-Pay |
| `SuXXES_ERPbased_M2SProcess_SustainabilityLog.xes` | ERP-based (SAP S/4HANA) | Make-to-Stock |
| `SuXXES_ERPbased_O2CProcess_SustainabilityLog.xes` | ERP-based (SAP S/4HANA) | Order-to-Cash |

All logs comply with the IEEE 1849-2023 XES standard and are validated
against the official XML schema.
